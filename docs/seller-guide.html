Seller guide · Order Tracker

Run your orders from WhatsApp

Send the bot a message in plain words. It saves the order, tracks status and sends your daily summary.

Stuck at any step? Tap 📖 Guide under any reply, or type kya karun.

  1. 1. Start setup

    Send start. Answer a few questions: shop name, city, and how many products you sell.

    Add products as Lawn Suit - 3500, one per line. Send done when finished.

  2. 2. Save a new order

    Copy the customer's message or type it. The bot reads the name, items, phone and address.

    • Example: Ayesha, 2 suit, 03001234567
    • Check the draft, then send YES.

  5. 5. Use the quick buttons

    After most replies the bot shows three buttons. Tap one instead of typing.

    • 📖 Guide — opens this guide and the step-by-step lessons
    • ➕ New order — starts a new order
    • 📦 Orders today — shows today's list

    Turn buttons off with shortcut off, back on with shortcut on.

واٹس ایپ سے اپنے آرڈر چلائیں

بوٹ کو آسان الفاظ میں پیغام بھیجیں۔ وہ آرڈر محفوظ کرے گا، اسٹیٹس دیکھے گا اور روزانہ کا خلاصہ بھیجے گا۔

کسی بھی مرحلے پر اٹکیں تو کسی بھی جواب کے نیچے 📖 گائیڈ دبائیں، یا لکھیں kya karun۔

  1. 1۔ سیٹ اپ شروع کریں

    لکھیں start۔ دکان کا نام، شہر اور پروڈکٹس کی تعداد بتائیں۔

    پروڈکٹ اس طرح لکھیں: Lawn Suit - 3500، ہر لائن میں ایک۔ ختم ہو جائے تو done لکھیں۔

    Order Tracker
    start
    خوش آمدید! سیٹ اپ شروع کریں؟
    سیٹ اپ شروع کریں
    گائیڈ دیکھیں

  2. 2۔ نیا آرڈر محفوظ کریں

    گاہک کا پیغام کاپی کریں یا خود لکھیں۔ بوٹ نام، آئٹمز، فون اور پتا خود پہچان لے گا۔

    • مثال: Ayesha, 2 suit, 03001234567
    • ڈرافٹ دیکھیں، پھر YES لکھیں۔
